# WavConverter 💽
`GoldSrc Audio Encoder`

Solusi konversi audio batch yang dikalibrasi khusus untuk **Counter-Strike 1.6** dan **Valstrike**. Menjamin kompatibilitas penuh dan stabilitas engine GoldSrc tanpa risiko *stutter* atau *crash*.

---

### 📦 Spesifikasi Teknis Output
Format dikunci secara permanen pada standar modding profesional:
- **Format:** WAV (Microsoft PCM)
- **Sample Rate:** 22050 Hz (High Quality)
- **Channels:** Mono (1-Channel)
- **Bit Depth:** 16-bit Signed
- **Metadata:** Clean (Tanpa junk data)

### 🚀 Fitur 
- **Manual Reorder:** Drag handle `⠿` untuk pengaturan urutan presisi.
- **Batch Processing:** Mendukung impor/ekspor massal via file `.zip`.
- **Smart Auto-Rename:** Penamaan otomatis (1-5) untuk kebutuhan Kill Sound Valstrike.
- **Local Conversion:** Pemrosesan 100% di browser. Tidak ada data yang diunggah ke server.

### 🕹 Penggunaan
1. **Import:** Masukkan file audio atau `.zip`.
2. **Organize:** Atur urutan file menggunakan drag handle.
3. **Rename:** Gunakan **Auto Rename** atau edit manual pada kolom input (Case-Sensitive).
4. **Convert:** Klik tombol **Convert** untuk mengekspor paket audio dalam format ZIP.
